# Doctors Schedule

A mobile application for managing and scheduling doctor appointments, developed as part of the 4th semester SWE250 Mobile App Development course.

## 📋 Overview

Doctors Schedule is a Java-based mobile application designed to help patients book appointments with doctors efficiently. The app provides a user-friendly interface for viewing doctor availability, scheduling appointments, and managing medical records.

## 🛠️ Tech Stack

- **Language**: Java
- **Build Tool**: Gradle
- **Project Type**: Mobile Application (Android)

## 📁 Project Structure

```
Doctors_Shedule/
├── app/                      # Main application source code
├── gradle/                   # Gradle wrapper files
├── build.gradle.kts          # Project-level build configuration
├── settings.gradle.kts       # Gradle settings
├── gradle.properties         # Gradle properties
├── gradlew                   # Gradle wrapper script (Unix)
├── gradlew.bat              # Gradle wrapper script (Windows)
└── .gitignore              # Git ignore rules
```

## 🚀 Getting Started

### Prerequisites

- Java Development Kit (JDK) 11 or higher
- Android SDK
- Gradle (or use the included Gradle wrapper)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/abra-r/Doctors_Shedule.git
cd Doctors_Shedule
```

2. Build the project using Gradle:
```bash
./gradlew build
```

3. Run the application:
```bash
./gradlew run
```

## 📱 Features

- View available doctors and their schedules
- Book appointments with doctors
- Manage existing appointments
- User-friendly interface for appointment management

## 🔄 Build & Development

This project uses Gradle as its build tool. Key build commands:

- Build the project: `./gradlew build`
- Run tests: `./gradlew test`
- Clean build: `./gradlew clean`
